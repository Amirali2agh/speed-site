# Speed Service

A cinematic React + Vite landing page for **Speed Service**, focused on network and IT services.

## Content

- Network setup and optimization
- Network security foundations
- Practical guides to TCP/IP, HTTP/HTTPS, DNS, and DHCP
- Interactive WebGL particle background
- Dedicated image slot for the upcoming Speed Service visual

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
